# Development archive

[`PROTOCOL-POC.md`](PROTOCOL-POC.md) is the historical engineering log, with test-environment setup details condensed for the October 19, 2026 protocol proof of concept, Stage 1 implementation, test-server setup, and integration tests.

It intentionally contains chronological snapshots: earlier sections report pending or blocked tasks, obsolete artifact versions, provisional assumptions, and test counts that were superseded later the same day. **Do not treat every historical status table as the current project status.** For the latest recorded real RPEngine PLAY-path result, see Sections 15.11–15.13 near the end of that report.

For current feature status and limitations, consult [README](../../README.md), [Architecture](../ARCHITECTURE.md), and [Test Plan](../TEST-PLAN.md). This archive is retained for reproducibility, not as installation instructions.

Command examples, paths, addresses, and dates in the report reflect a particular temporary test environment and should not be copied into production unchanged.
